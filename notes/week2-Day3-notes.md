## 今日学习内容
### 什么是模块
- 模块就是一个 .py 文件，文件中写了函数、变量或类，供其他文件导入使用
- 为什么需要模块：代码按功能拆分，清晰、好维护、可复用
- 模块的三种来源：内置模块（math/random/json等，python自带的模块）、第三方模块（requests/numpy等，通过pip安装的）、自定义模块（自己写的 .py 文件）

### import 和 from...import 的区别
#### import 模块名
- 导入整个模块，使用时必须加模块名前缀：`math.sqrt()`
- 优点：函数名之间不会互相冲突，清晰
- 缺点：要写模块名，比较麻烦

#### from 模块名 import 函数名
- 只导入对应模块的对应函数，使用时直接写函数名：`squrt()`
- 优点：简洁
- 缺点：可能和自己定义的函数名同名，发生冲突

#### from 模块名 import *
- 将模块中的所有函数拆开并全部导入，使用时直接写函数名：`squrt()`
- 极易与自己定义的函数名同名，发生冲突，不推荐使用

### 包
#### 什么是包
- 包本质就是一个文件夹，该文件夹中可以包含若干给 python 模块（.py 文件）文件夹中还包含了一个 `__init__.py` 文件
- 包的作用：模块文件较多时，用来容纳管理多个模块（包本质也是一个模块）

#### 包的导入方法
- import 包名.模块名：导入对应包中对应的模块，使用时必须加包名和模块名的前缀（`包名.模块名.函数名()`）
- from 包名 import 模块名：与 `import 包名.模块名` 作用一致，但在使用时只加模块名的前缀（`模块名.函数名()`）
- from 包名 import * ：将对应包中所包含的所有模块导入，使用时加模块名的前缀（`模块名.函数名()`）（使用该命令时`__init__.py`文件夹中必须要有已赋值的特殊变量 `__all__`）
- from 包名.模块名 import 函数名：导入对应包中对应模块内的对应函数，使用时直接调用函数名
- from 包名.模块名 import * ：导入对应包中对应模块内的所有函数，与模块中的 `import *` 作用一致，使用时直接调用函数名；极易与自己定义的函数名同名，发生冲突，不推荐使用

### `__name__ == "__main__"`的原理
- `__name__` 是python的特殊变量，它的值取决于文件是直接运行还是被导入
- 直接运行时：`__name__ == "__main__"`
- 被导入时：`__name__ == 模块名` （如 "geometry"）
- `if __name__ == "__main__"` 的作用：只有文件直接运行时才执行下面的代码，被导入时不执行
- 好处：模块文件可以用这个代码直接在文件内部验证代码是否可以运行，同时也不影响该模块文件作为工具导入其他文件

### pip 安装第三方库
- pip 是 python 的包管理工具，像手机的应用商店
- pip install 库名：安装对应的库
- pip list：查看已安装的库
- pip show 库名：查看对应库的信息
- pip freeze > requirements.txt：导出所有库到 requirements.txt 文件
- 第三方库安装在 site-packages 文件夹内

### 模块搜索路径
- Python 按顺序搜索：当前目录 ——> PYTHONPATH ——> 标准库目录 ——> 第三方库目录（site-packages）
- 主程序文件要用到的自定义模块要和主程序文件放在同一个文件夹中
- 可以用 `import sys`；`print(sys.path)` 查看所有搜索路径
- 包的搜索路径
    - 相对路径（import 包名.模块名）：从主程序文件所在目录开始查找，若包文件与主程序文件不在同一目录中，则会查找失败
    - 绝对路径（import 根目录名.包名.模块名）：从项目的根目录开始查找，不受主程序文件位置的影响

### 特殊变量 `__all__`
- `__all__`是一个模块级别的特殊变量，用于指定（from 模块名 import */ from 包名 import *）时导入哪些（函数/模块）
- 在模块中：`__all__`通常写在模块文件的最前端，写法是 `__all__ = [函数名1，函数名2，...]`，用 import * 导入时，只导入 `__all__` 所对应的函数
- 在包中：`__all__`必须写在包文件夹的 `__init__.py` 文件内，写法是 `__all__ = [模块名1，模块名2，...]`,用 import * 导入时，只导入 `__all__` 所对应的模块
