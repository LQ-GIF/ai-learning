## 本周知识主线
请求一个 API 的完整过程：
发送请求（GET/POST）——> 带参数（params 在 URL 上/ json 在请求体里）——> 带请求头（headers，鉴权放 Authorization: Bearer）——> 设置超时（timeout）——> 处理失败（4xx 不重试/5xx 和网络异常重试）——> 结果保存为 JSON ——> 重复逻辑抽成函数复用

## 印象最深的一个错误
印象最深的是 Day6 中测试封装函数的代码中出现的错误
    - 现象：防御逻辑里连接失败应重试 3 次后提示报错，现实代码运行时只重试 1 次后就提示报错
    - 原因：封装函数代码中把重试次数耗尽后的总结代码写在了 for 循环内，总结代码中有 return，导致 for 循环在第一遍循环结束时读取到了 return，自动跳出了循环
    - 解决方法：将总结代码写在 for 循环代码块的外面
    - 教训：在写代码时，要先理清楚这段代码的逻辑再动手，要清楚每个代码块的具体作用
