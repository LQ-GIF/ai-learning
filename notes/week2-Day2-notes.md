## 今日学习内容
### 可变参数 *args
- 可以接收任意多个位置参数，并打包成元组
- 例子：def f(*arge)： ... 调用 f(1, 2, 3)，arge = (1, 2, 3)
- arge是名字，不固定，关键是前面的 `*`
- 适合上传参数数量不确定的情况（求和、排序等）

### 可变参数 **kwargs
- 可以接收任意多个关键词参数，并打包成字典
- 例子：def f(**kwargs): ... 调用 f(x="1", y="2", c="3"), kwargs = {"x": 1, "y": 2, "c": 3}
- keargs是名字，不固定，关键是前面的 `**`
- `*args` 与 `**kwargs` 在同一个函数内时，`*args` 必须在 `**kwargs` 前面

### lambda 匿名函数
- 一行定义的简洁函数，不需要 def 和函数名
- 语法：`lambda 参数: 表达式`
- 自动 return 表达式的结果，不需要另写 return
- 只能写一行代码，不能写多行代码、循环、赋值，在函数逻辑比较简单（单行表达式）且只在一个地方使用时，可以考虑使用 lambda（匿名函数）
- 常用场景：作为参数传给另外一个函数（如 sorted 的 key（排序方式））
- 适合简单的、只调用一次的函数

### 函数作为参数（sorted 的 key）
- sorted 的 key 参数接收一个函数，调用函数的返回值作为排序依据
- 常用 lambda（匿名函数）作为 key，因为 lambda 简洁
- 例子：`sorted(case, key=lambda c: c["建筑年份"])` 按建筑年份排序
- key 只计算排序依据，不修改原数据
- reverse 默认为Flase（默认升序），reverse=True 时，排序为降序
