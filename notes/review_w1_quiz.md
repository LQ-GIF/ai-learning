## 第 5 题 `[简答]`
- name = "西湖美术馆"
  area = 1200
  - 用 f-string 输出：`西湖美术馆的面积是1200平方米`（写出完整代码）
  - 说明 f-string 里 `{area}` 和 `{area:.2f}` 有什么区别，`:.2f` 里的 `.2` 和 `f` 各代表什么？
- 答案：
    print(f"{name}的面积是{area}平方米")
    `{area}` 的数据类型为 int，`{area:.2f}` 的数据类型为 float。`.2` 表示小数位数，`f`是小数 float 的缩写，表示小数
- 正确答案：
    *`{area}` 和 `{area:.2f}` 的数据类型都为 str。area 本身的数据类型仍然为 int，`.2f` 只是控制显示成 2 位小数，`.2` 是小数位数，`f` 是定点小数格式的标记*

    **变量 `area` 从头到尾都是 int，没有变过。** f-string 的作用是 “把这玩意按某种样子显示出来”，**显示结果永远是字符串**。

## 第 6 题 `[填空]`
- lst = [1, 2, 3]
  lst.append(4)
  lst.insert(0, 0)
  lst.pop()
  lst.remove(2)
- 执行完，`lst` 的值是什么？
  再回答：`append` / `insert` / `pop` / `remove` 这四个方法各删 / 加什么位置的东西？用一句话分别说明。
- 答案：
    [0, 1, 3]
    `append` 将数据添加在列表末尾
    `insert` 将数据添加在指定的索引位置
    `pop` 删除指定索引位置的数据，并返回；不指定索引位置时，默认删除列表末尾的数据，并返回
    `remove` 删除列表中第一个匹配的数据，与 `pop` 不同的是，他并不返回数据
    **remove 传入的参数是数据本身，不是该数据的索引位置**

## 第 9 题 `[写输出]`
- a = [1, 2, 3]
  b = a
  b.append(4)
  print(a)
  - 输出什么？
  - 如果把第 2 行改成 `b = a[:]`，`print(a)` 又输出什么？
  - 用一句话解释两次结果为什么不一样（关键词：指向同一个 / 复制一份）。
- 答案：
    [1, 2, 3, 4]
    不知道
    不知道
- 正确答案：
    *[1, 2, 3]*
    *原因一句话：`b = a` 让两个名字指向同一个列表（`b` 只是别名）；`b = a[:]` 造了一个新列表（复制）*

    **列表、字典这类 “可变对象”，`=` 只是起别名，不是复制。要复制列表用 `[:]`，复制字典用 `.copy()`。**

## 第 10 题 `[写输出]`
- for i in range(1, 10, 3):
      print(i, end=" ")
  - 输出什么？
  - `range(1, 10, 3)` 里的 `1`、`10`、`3` 各代表什么？
  - `range(10)` 和 `range(1, 10)` 有什么区别？
- 答案：
    3  6  9
    `1` 表示起始数据，range()得到的数据从它开始；`10` 表示终止数据，range()得到的数据不包括它
    `range(10)` 是从 0 开始；`range(1, 10)` 是从 1 开始
- 正确答案：
    *1  4  7*
    *`3` 代表步长*

    **从 1 开始，每次加 3：1 → 4 → 7（下一个 10 到了终点，不含，所以停）**
    **注：起始数据不参与步长计算**

## 第 11 题 `[写输出]`
- total = 0
  for n in range(1, 11):
      if n == 5:
          continue
      if n == 8:
          break
      total += n
  print(total)
  - 输出什么？（要写出计算过程，说明哪几个数被加了、在哪一步停的）
  - 如果把 `continue` 和 `break` 两块的位置互换（先判断 8 再判断 5），输出又是什么？
- 答案：
    0 + 1 + 2 + 3 + 4 + 6 + 7 = 23
    如果只互换两个条件的位置，`continue` 和 `break` 不互换，则结果为：0 + 1 + 2 + 3 + 4 = 10
    如果是两个 if 代码块相互调换，则结果为：0 + 1 + 2 + 3 + 4 + 6 + 7 = 23, 结果不变

## 第 12 题 `[简答]`
- 写一段代码，只用一个双重 for 循环和 if 判断，打印出下面的图形：
  *
  * *
  * * *
  * * * *
  限制：不能用 `"*" * n` 这种字符串乘法直接拼出整行，必须靠内层循环一个一个打印。
  再回答：这段双重循环里，内层循环总共执行了多少次？（写出你是怎么算的）
- 答案：
    for i in range(1, 5):
        for j in range(1, i + 1):
            print("*", end=" ")
        print()
    外层第 1 次循环，内层循环 1 次
    外层第 2 次循环，内层循环 2 次
    外层第 3 次循环，内层循环 3 次
    外层第 4 次循环，内层循环 4 次
    故内层循环总次数为 1 + 2 + 3 + 4 = 10 次
