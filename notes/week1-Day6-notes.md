## 今日学习内容
### 什么是循环
- 让程序重复执行一段代码，不用一遍一遍的写
- 两种循环：for 循环和 while 循环

### for 循环
- 基本结构：for 变量 in 待处理的数据集:
                循环体代码
- 适合循环次数已知或确定的情况（遍历列表、遍历字典、打印1-100）
- 遍历列表：`for items in list:`
- 遍历字典：`for keys in dict:`

### range() 函数
- 生成指定范围的数字序列，配合 for 循环使用
- range(5):0，1，2，3，4（从0开始，到5结束，不包含5）
- range(1, 6):1，2，3，4，5（从1开始，到6结束，不包含6）
- range(1, 6, 2):1，3，5（从1开始，到6结束，步长为2，不包含6）

注：range() 函数包前不包后，结束的数字是不包含的

### while 循环
- 基本结构：while 条件:
                循环体代码
- 适合不知道循环次数的情况
- 条件成立就重复执行，条件不成立就退出
- 注意：循环体代码里一定要包含改变条件的代码，否则代码会进入死循环

### for 循环和 while 循环的区别
- for 循环：根据数据范围判断循环是否开始，知道循环次数，不会进入死循环
- while 循环：根据条件是否成立来判断循环是否开始，循环次数不确定，若条件始终成立，则代码会进入死循环，故 while 循环中要有改变条件的代码

### break 和 continue 的区别
- break：跳出当前循环，循环结束
- continue：跳过本轮循环，进入下一轮循环，循环继续

### 循环嵌套
- 循环里还有一层循环
- 外层循环执行一次，内层循环执行完整的一轮
- 九九乘法表就是典型的循环嵌套，外层控制行，内层控制列

### print() 的 end 参数
- 默认 `print()` 执行完会自动换行
- `end=" "` 表示执行完成后用空格结尾，不换行
- `end=""` 表示执行完成后什么都不加，也不换行
- 九九乘法表中每行的每一个算式用 `end=" "`结尾，一行写完用 `print()` 换行

## 补充 Day5 内容
### match...case... 结构模式匹配
- 用一个清晰的模板去精准的匹配数据的结构和内容，匹配成功则执行对应的操作
- 执行流程：
    - 计算 match 指定的表达式的值
    - 计算结果从上到下依次和 case 后面的值进行匹配，匹配成功则执行对应的代码
    - 若所有的 case 都没匹配上，则执行默认的 `case _ ` 对应的代码
- 应用场景：基于某个变量的多个固定值进行分支判断时，可以使用 match 模式匹配

注：
match 模式匹配功能只在 Python 3.10及后续版本中有效，属于3.10版本更新的新语法
match 模式匹配的应用场景有限，并不能完全替代 if 语句

## 遇到的问题
- 问题1：
    - 现象：打印棋盘程序中，打印出来的都是黑色格子
    - 原因：代码中 if 语句的条件为 `i/j % 1 == 0` 这个条件在任何时候都成立，故打印出来的都是黑色
    - 解决方法：将条件中的 1 改为 2 
- 问题2：
    - 现象：在加入冻结系统的登陆系统程序中，运行时直接跳冻结提醒
    - 原因：代码中 while 循环的条件为 `d == 5` 而在这之前为 d 赋的值为 1 ，这种情况下，设定的条件永远不成立，故直接跳冻结提醒
    - 解决方法：将条件修改为 `d <= 5`
