## 今日学习内容
### 什么是函数
- 函数是组织好的、可重复使用的、用来实现多个功能的代码片段（将一段代码打包起来，起个名字，用的时候直接调用）
- 函数的优点：代码复用、结构清晰、便于修改、可以返回结果

### 定义函数的语法
- def 函数名(参数1，参数2，...):
-     函数体（功能代码，这个函数具体实现什么功能）
-     返回值 return （函数体执行得出的结果由这里返回）

注：函数必须先定义后调用执行，定义函数时内部代码并不会执行，调用函数时内部代码才会执行

### 三种参数类型
#### 位置参数
- 按顺序传递，调用时必须按照定义的参数顺序来传
- 例子：def f(a, b):... 调用 f(1, 2)

#### 默认参数
- 定义时给参数一个默认值，调用时不对这个默认参数进行赋值，代码执行时就用定义时给定的默认值
- 默认参数必须放在位置参数的后面
- 例子：def f(a, b=10):... 调用 f(5)时，a=5, b 默认等于10

#### 关键字参数
- 调用时用 `参数=值` 的方式传参，由于参数被指定，所以顺序可以随便换
- 例子 def f(a, b):... 调用 f(b=10, a=5)
- 可以和位置参数混合使用

### return 返回值
- 函数执行完，把结果返回给调用的地方
- 没有 return 的函数会返回 None
- return 会立即结束函数，return 后面的代码不会执行
- return 可以返回多个值
- 区别：没有 return 时输出的结果是"只读模式"，有 return 时输出的结果可以进行调用

注：return 只起到返回作用，没有输出作用

### 变量域的作用
#### 局部变量
- 在函数内部定义的变量
- 只能在函数内部使用，在函数外部调用不了

#### 全局变量
- 在函数外部定义的变量
- 整个文件都可以调用这个变量，在函数内部修改全局变量时，需要用 global 声明
- 例子：global count；count += 1

注：尽量避免在函数中使用全局变量，这样会使代码难以维护和调试，global 主要用在程序的状态、配置和计数器等场景中

### 函数的嵌套调用
- 在一个函数中，调用了另外一个函数
- 函数的调用遵循栈结构，最后被调用的函数，其结果会最先返回（后进先出）
- 例子：def f():
-          ...
-          e()
- 
-      def e():
-          ...
