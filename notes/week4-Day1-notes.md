# W4 Day1 学习笔记：类型标注与 mypy 入门
日期：2026/10/26

## 今日学习内容
- 函数参数的类型标注：参数名: 数据类型
- 函数返回值类型标注：-> 数据类型
- 变量类型标注：变量名: 数据类型 = 初始值
- 容器类型：`List[str]`，`Dict[str, int]`
- `Optional[Dict]`：可能是字典，也可能是 None
- mypy 静态类型检查：运行前扫描数据类型是否匹配

## 类型标注有无对比
| 对比项 | 无标注 | 有标注 |
|---|---|---|
| 代码可读性 | 要翻函数内容猜数据类型 | 一眼看出参数和返回值的数据类型 |
| 工具检查 | 无 | mypy 可提前发现数据类型错误 |
| 运行时行为 | 不强制检查 | 不强制检查（标注只是标签，起到提醒作用） |

## 类型含义表
| 类型 | 含义 | 我举的例子 |
|---|---|---|
| `int` | 整数 | 1, 2 |
| `str` | 字符串 | "Hello" |
| `float` | 小数 | 1.1, 2.1 |
| `bool` | 真/假 | Ture/False |
| `List[str]` | 字符串列表 | ["A", "B", "C"] |
| `Dict[str, int]` | 键字符串、值整数的字典 | {"张三": 100, "李四": 99} |
| `Optional[Dict]` | 字典或 None | |
