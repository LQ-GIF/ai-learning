# W4 Day4 学习笔记：Git 分支、冲突与 PR
日期：2026/10/29

## 今日学习内容
- git branch / switch / merge 三个核心命令
    - `git branch`：查看当前所有分支，`*` 在哪个分支上就说明目前处于哪个分支
    - `git branch -m 新分支名`：将当前分支的分支名改为新的分支名
    - `git branch -d 分支名`：删除指定分支
    - `git switch 分支名`：切换到指定分支
    - `git switch -c 新分支名`：新建分支并切换到该分支
    - `git merge 分支名`：把指定分支合并到当前分支
    - `git push -u origin 分支名`：把本地分支推送到 GitHub
    - `git pull`：拉取当前项目的最新版本
- 分支命名惯例：feature/功能名
- 冲突标记：`<<<<<<< HEAD / ======= / >>>>>>> 分支名`
- PR 流程：push 分支 → 网页 Compare & pull request → Merge

## 知识点对比表
### main 直推 vs 分支 + PR
| 对比项 | 直接在 main 上改 | 分支 + PR |
|---|---|---|
| 风险 | 改坏直接影响正式版本 | 改坏只影响分支 |
| 评审 | 没有 | PR 页面可以讨论 |
| 适用 | 个人小项目 | 团队协作项目的重要功能 |

### 冲突标记
| 标记 | 意思 |
|---|---|
| <<<<<<< HEAD | 当前分支（main）的版本从这里开始 |
| ======= | 两个版本的分隔线 |
| >>>>>>> 分支名 | 另一分支的版本到这里结束 |
