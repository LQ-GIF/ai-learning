## 今日学习内容
### 运算符
#### 算术运算符
- `+` （加）、`-` （减）、`*` （乘）、`/` （除）（运算结果是小数）
- `//` 整除（只取整数部分）
- `%` 取余 （取除法的余数部分）
- `**` 幂次方
- 例子：`5 // 2 = 2` 整除，`5 % 2 = 1` 取余，`5 ** 2 = 25` 幂次方

#### 比较运算符（返回True/False）
- `==` 等于（注意是两个等号）
- `!=` 不等于
- `>` 大于
- `<` 小于
- `>=` 大于等于
- `<=` 小于等于

注：`==` 是比较，是'等于吗？'的意思，`=` 是赋值的意思，两个符号代表的意思完全不一样

#### 逻辑运算符（多个条件组合）
- and 与（并且）：两个条件都满足才是True
- or 或（或者）：两个条件满足任意一个就是True
- not 非（取反）：把结果反过来

#### 成员运算符
- in 在...里
- not in 不在...里

#### 赋值运算符
- `=` （赋值运算符）：把 `=` 右边的值赋给左边的变量，如：num = 1 + 2，num的值为3
- `+=` （加法赋值运算符）：num += 2 等效于 num = num + 2
- `-=` （减法赋值运算符）：num -= 2 等效于 num = num - 2
- `*=` （乘法赋值运算符）：num *= 2 等效于 num = num * 2
- `/=` （除法赋值运算符）：num /= 2 等效于 num = num / 2
- `%=` （取余赋值运算符）：num %= 2 等效于 num = num % 2
- `//=` （整除赋值运算符）：num //= 2 等效于 num = num // 2
- `**=` （幂赋值运算符）：num **= 2 等效于 num = num ** 2

### if 条件判断
#### if 单分支
- if 条件:
    条件成立时执行的代码

#### if ... else ... 双分支
- if 条件:
    条件成立时执行的代码
  else
    条件不成立时执行的代码

#### if ... elif ... else ... 多分支
- if 条件1:
    条件1成立时执行的代码
  elif 条件2:
    条件1不成立但条件2成立时执行的代码
  ...
  else:
    以上条件都不成立时执行的代码
- 执行逻辑：从上到下依次判断条件是否成立，第一个成立的条件会被执行，执行完成后立即跳出该 if 语句，不在判断后面的条件

#### 嵌套 if
- if 里面还有 if ，先判断外层，外层成立在判断内层

#### 缩进的重要性
- Python 用缩进（四个空格）区分代码块，不是用花括号
- if/elif/else 下面的执行代码必须缩进
- 同一个代码块的缩进必须一致

注：：若当前条件下的执行代码想之后补齐，可以用 `pass` 占住执行代码位置，`pass`也要缩进
