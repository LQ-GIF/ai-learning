# W3 Day1 学习笔记：HTTP 与 API 基础
日期：2026/10/19

## 今日学习内容
- HTTP 是什么：互联网上的"快递协议"，规定了请求和响应的标准流程
- API 是什么：服务器提供的"服务窗口"，程序员通过 API 获取数据
- requests 库：Python 的 HTTP 客户端，用来发送请求和接收响应
- GET 请求：最常用的请求方法，表示"我要获取数据" 
- 状态码：服务器返回的状态，200=成功、404=找不到、500=服务器出错
- 响应头：服务器返回的附加信息（内容类型、日期、服务器类型等）
- response.json()：把 JSON 字符串解析成 Python 字典

## 常见状态码
| 状态码 | 含义 | 例子 |
|---|---|---|
| 200 | 访问成功 | 正常访问网页 |
| 301 | 永久重定向 | 网址换了，自动跳转 |
| 400 | 请求错误 | 参数不对 |
| 401 | 未授权 | 需要登陆 |
| 403 | 禁止访问 | 没有权限 |
| 404 | 找不到 | 网址不存在 |
| 500 | 服务器错误 | 服务器出bug了 |

## 遇到的问题
- 问题1：
    - 现象：写好的代码运行后，返回的状态码显示404
    - 原因：404表示该网址不存在，检查url定义的网址信息发现网址输入错误
    - 解决方法：输入正确的 API 网址
- 问题2：
    - 现象：问题1解决后，运行代码出现'KeyError'错误
    - 原因：KeyError 表示键值错误，检查对应的报错内容发现键名输入错误
    - 解决方法：输入正确的键名
