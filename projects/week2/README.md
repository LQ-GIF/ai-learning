# 建筑案例管理工具（case_manager_v3）
## 项目介绍
【一个用于收集和管理建筑案例信息的简易的命令行工具，支持对建筑案例信息的增删查改，所有建筑案例信息都保存在 `cases_v3.json` JSON 文件内。该工具配有异常处理和日志记录功能，日志记录功能可以实时记录使用者的每一步操作和每一处出现的错误，并将信息记录在 `case_manager.log` 日志文件内，异常处理功能可以确保使用者在输入非法数据时，程序不发生崩溃，并将错误信息同步传入日志文件内。】

## 功能列表
- 录入新的建筑案例（建筑名称、所在地址、建成年份、建筑师、所属风格或流派）
- 查看所有已添加的建筑案例信息
- 按建筑名称搜索建筑案例信息
- 按序号删除已添加的建筑案例信息
- 数据自动保存到 `cases_v3.json` JSON文件内
- 实时记录使用者的每一步操作和出现的错误，并同步给 `case_manager.log` 日志文件

## 环境要求
- Python 3.6 及以上（推荐 3.8 +，开发环境为3.13）
- 不需要额外安装第三方库（只用 python 自带的 os/json/logging）

## 安装与运行
### 1. 克隆仓库
``` git clone https://github.com/LQ-GIF/AI-Learning.git ```

### 2. 进入项目目录
``` cd AI-Learning/projects/week2 ```

### 3. 运行程序
``` python case_manager_v3.py ``` （VS Code 用户直接点击代码窗口右上角的 "三角形" 运行键即可运行程序）

**首次运行时，程序会自动在当前所在目录生成 `cases_v3.json` 数据文件，无需手动创建**

## 项目结构
```
week2/
├── case_manager_v3.py   # 项目主程序
├── cases_v3.json        # 案例数据存储文件（程序自动生成）
├── case_manager.log     # 项目日志文件（程序自动生成）
└── README.md            # 本项目使用说明文档
```

## 已知限制
- 数据存储在本地 JSON 文件，不支持远程多人同时编辑
- 没有用户登陆和权限管理（切勿将重要信息上传，避免造成损失）
- 界面为命令行形式，没有图像界面
- 搜索功能只支持精确名称匹配，不支持模糊搜索
